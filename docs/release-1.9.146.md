# 1.9.146 首页回底栏 · 部落占位

## 变更
1. **底栏**：恢复 **首页**，与赛程 / 预测 / 数据 组成四 Tab；首页内容为原态度流（焦点赛事、比赛态度、专栏作者等）。
2. **部落**：顶栏「部落」独立为 `#/tribe` 占位页（筹备中说明），不再等同 `#/home`。
3. **顶栏居中**：部落 | 头条 | 开奖 相对整栏光学居中（左右等宽槽位 + 中部 Tab）。
4. **首页清理**：移除快捷图标行（赛程/预测/专栏/数据/开奖）；「比赛态度」标题旁去掉「我的知识库」「全部预测」（知识库仍可从侧栏抽屉进入）。

## 版本
- Web / `config.js` / `sw.js`：**1.9.146**（`jc-v1.9.146`）
- Android 默认：`VERSION_NAME=1.9.146`、`VERSION_CODE=183`

## 验证
1. 底栏可见 **首页** 且进入态度流首页；点顶栏 **部落** 进入占位页，非首页。
2. 顶栏三 Tab 视觉居中；搜索 / 消息图标仍可用。
3. 首页无白色快捷行；比赛态度区无右侧两个链接。
4. `node tools/ui-test.js` 通过（含部落占位与首页断言）。
