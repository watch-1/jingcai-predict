# 1.9.148 赛程顶栏三钮 · 赛事详情紧凑顶栏

## 变更
1. **赛程顶栏**：底栏在「赛程」时，顶栏中部替换为 **关注 · 未开始 · 已结束**（驱动 `jc_sch_mode` 过滤）；左上头像、右上搜索/信箱保留。离开赛程后恢复 **部落 · 头条 · 开奖**。
2. **赛程页布局**：日期条下方移除重复的三钮行；联赛 pills 与列表逻辑不变。
3. **顶栏架构**：`topChromeCenterHtml` 按底栏上下文切换中部 Tab 集，便于后续为预测/数据等页扩展专属顶栏按钮。
4. **赛事详情**：回退与「关注」缩小并贴顶安全区；减少 hero 顶部 padding，球队信息与 Tab 整体上移（无「赛事详情」白条页眉）。

## 版本
- Web / `config.js` / `sw.js`：**1.9.148**（`jc-v1.9.148`）
- Android 默认：`VERSION_NAME=1.9.148`、`VERSION_CODE=185`

## 验证
1. 底栏赛程：顶栏中间为三钮，可过滤列表；日期下无 `.sch-mode` 行。
2. 底栏首页：顶栏恢复部落/头条/开奖。
3. 赛事详情：顶栏控件更小、内容更靠上。
4. `node tools/ui-test.js` 通过（赛程/顶栏相关断言；详情赔率断言与 main 一致，依赖环境数据）。
