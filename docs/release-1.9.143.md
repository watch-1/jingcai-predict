# 1.9.143 App Chrome 重设计（部落 / 头条 / 开奖）

## 产品
- **顶栏**：左侧圆形头像打开「我的」侧滑抽屉（fig2 风格分组卡片）；中间 **部落 | 头条 | 开奖** 顶 Tab（选中加粗 + 绿色下划线）；右侧搜索与消息入口。
- **底部 Tab**：保留 **赛程 / 预测 / 数据**，移除「我的」与重复的「首页 / 开奖」。
- **映射**：部落 → 首页「比赛态度」与社区向内容；头条 → `#/news` 体坛资讯；开奖 → `#/results`。
- **取消**：主界面居中深蓝标题栏（如「赛程」）+ 深色日期条外观；赛程/开奖日期条改为浅色 pill 样式。

## 保留
- 知识库、预测双入口、赛事详情、悬浮足球 GLB/CSS 回退、平台态度简报、画布复盘 unwrap 等既有能力未删。

## 版本
- Web / `config.js` / `sw.js`：**1.9.143**（`jc-v1.9.143`）
- Android 默认：`VERSION_NAME=1.9.143`、`VERSION_CODE=180`

## 验证
1. 头像 → 侧栏抽屉；抽屉内可进方案/会员/知识库/设置。
2. 顶 Tab 切换部落 / 头条 / 开奖，内容对应变化。
3. 赛程页无居中深蓝「赛程」大标题；日期条为浅色。
4. 底部仅赛程、预测、数据三项。
