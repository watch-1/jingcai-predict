# 1.9.142 热修：知识画布空态 + 赛后复盘去包裹

## 问题
1. **知识包画布**：已有节点时仍显示「画布为空…」半透明提示（添加节点后未同步隐藏）。
2. **赛后复盘**：Tab 仍套用赛事详情 `md-wrap` 海军蓝内容包裹，宽表列被裁切、中间出现大块空蓝带。

## 修复
- `syncKbCanvasEmptyHint()`：保存/删除节点及挂载画布后按条目数显示或隐藏 `#kb-canvas-hint`。
- 复盘 Tab：`viewWrapClass` 使用 `md-wrap--review` 且**不再**叠加 `md-wrap`；CSS 改为浅底 + 扁平 `.dsec`，宽表可横滑。

## 版本
- Web / `config.js` / `sw.js`：**1.9.142**（`jc-v1.9.142`）
- Android 默认：`VERSION_NAME=1.9.142`、`VERSION_CODE=179`

## 验证
1. 空画布 → 添加节点 → 提示立即消失；退出再进有节点的包 → 无提示。
2. 已完场比赛 →「赛后复盘」：无海军蓝内容包裹；指标对照表列完整、可横滑。
