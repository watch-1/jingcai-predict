# 1.9.138 首页「比赛态度」信息流

## 改动
- 首页移除「今日高信心预测」横滑条与「热门赛事」列表，改为纵向 **比赛态度** 风格卡片流。
- 卡片内容来自现有 **平台简报 / 信心指数 / 推荐表态** 与 `shortReason` 摘要，无虚构专家、已购人数或付费豆。
- 列表区保留浅色 pastel 底；**上滑滚动** 时海军蓝包裹层自左上向右下渐显（`--ha-p` / 对角 mask），白卡不被裁切。
- 顶栏搜索、快捷入口、专栏作者、体坛资讯与底栏 Tab 不变。

## 版本
- `config.js` / `sw.js` **1.9.138**；Android 默认 `VERSION_NAME=1.9.138`、`VERSION_CODE=175`。

## 验证
1. 打开首页：仅见「比赛态度」竖列表，无高信心横滑与热门赛事块。
2. 卡片可点进单场详情；右侧为大号信心 %。
3. 在列表区上滑：深蓝包裹由左上向右下铺开，过渡平滑、无布局跳动。
