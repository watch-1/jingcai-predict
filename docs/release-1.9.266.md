# 1.9.266 — 手机端队名完整显示

## 问题
- 赛程/比分列表在常见手机宽度上把「长崎成功丸」「FC东京」「阿德莱德联」等截成「长崎…」「东京…」「阿德…」。
- 根因：中栏 `--match-mid-col: 120px` 固定过宽，两侧 `1fr` 名列被挤窄；队名又是单行 `nowrap + ellipsis`。VS 两侧的空白是中栏，不是名列没用完。
- 1.9.261 中心靠拢布局用户已否决，不能靠把队名组往 VS 上贴来「省出」宽度。

## 适配（流体，不是单一机型死值）
- **桌面 / 平板（≥480px）**：`--match-mid-col` 仍 120px，横向贴边几何与 1.9.260/262 相同。
- **手机（≤479px）**：中栏改为 `clamp(76px, 22vw, 100px)`。约 360 CSS px 时 ~79px，给名列多出约 40px；窄到 320 时不低于 76px，保证「1 - 0」「下半场 86'」仍单行可读。列间距同步 `clamp(6px, 2.2vw, 10px)`。
- **队名**：`clamp(12px, 3.65vw, 13.5px)` + 最多两行换行（`-webkit-line-clamp: 2`）。短中文名（长崎成功丸 / 蔚山现代 / 阿德莱德联）在 360–430 上优先单行完整显示；极长名先换行，两行仍放不下才省略。
- 主队 `flex-start` + 左对齐，客队 `flex-end` + 右对齐；队名 `flex: 1 1 auto` 吃满本列。徽标保留。进行中比分仍为品牌蓝。
