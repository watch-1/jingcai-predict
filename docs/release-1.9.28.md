# 1.9.28 观望卡片圆环对齐「观望指数」（修误导性 42）

## 问题
1.9.27 选择性表态后，列表观望卡右上圆环被前端强制 `Math.min(pr.conf, 0.42)`，几乎一律显示 **42**；底部「观望指数」仍是真实 `pr.conf`（约 59–69%）。用户误以为模型信心从 ~70 崩到 42。

## 结论
- **模型 conf 未因观望下调**；仅 `lvl` 改为观望、表态文案改为「与盘口一致 / 信息不足」。
- 圆环 42 是 **前端 UX 硬顶**，不是 selective 规则本身；一律 ~42 是 bug（误导）。

## 修复
- `public/app.js`：观望卡圆环改为展示真实 `pr.conf`（与「观望指数」一致），并用灰色 muted 描边，避免红/蓝「强信心」色。
- 选择性表态逻辑（`lib/predict-report.js`）不变。
