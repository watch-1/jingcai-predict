# 1.9.145 恢复顶栏搜索入口（Hotfix）

## 背景
1.9.144 误将「顶栏常驻搜索条」与「搜索功能」一并下线。用户仅需去掉首页/顶栏内的 pill 搜索条（「请输入查询的内容」），**搜索图标**与全局 `#/search` 页应保留。

## 变更
1. **顶栏**：在消息图标左侧恢复搜索放大镜按钮，点击进入 `#/search` 全局搜索页。
2. **不恢复**：顶栏/首页内始终可见的搜索条 UI；部落首页仍无 `home-search-hdr`。
3. **保留 1.9.144**：部落/头条/开奖顶 Tab 与底栏工具 Tab 行为、无 shell 大标题、赛事详情 edge-to-edge hero 等。

## 版本
- Web / `config.js` / `sw.js`：**1.9.145**（`jc-v1.9.145`）
- Android 默认：`VERSION_NAME=1.9.145`、`VERSION_CODE=182`

## 验证
1. 部落顶栏右侧可见 **搜索** + **消息** 两个图标。
2. 点搜索进入搜索页，可输入关键词；顶栏无常驻搜索条。
3. `#/search` 深链不再被重定向回部落。
