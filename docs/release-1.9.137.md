# 1.9.137 赛后复盘去掉内容包裹层

## 问题
赛事详情「赛后复盘」Tab 内容被双层海军蓝/圆角白卡包裹，宽表格右侧列被裁切，无法完整查看或横滑。

## 改动
- 复盘 Tab 激活时：`#view` 增加 `md-wrap--review`，`#detail-pane` 增加 `detail-pane--review`（软切换 Tab 时同步）。
- CSS：复盘内容区取消 `.dsec` / `.pmr-wrap` 卡片壳与 pitch 主题下的深色外框；保留 hero / Tab 条与其它 Tab 的 `md-wrap` 海军蓝底。
- 指标对照表容器保持 `overflow-x: auto`，不再被外层圆角裁切。

## 验证
1. 打开已完场比赛 →「赛后复盘」：无额外深蓝圆角包裹；指标对照表可横滑且列完整可见。
2. 切换到「情报/赔率」等 Tab：仍为白卡浮在海军蓝底上（行为不变）。
