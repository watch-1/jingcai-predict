# 1.9.194 比赛态度卡片包裹色：淡金→银灰

## 问题
1.9.193 卡片 `::before` 仍使用天蓝光晕（`rgba(168,206,255…)`），与产品要求的 **淡金色渐变成银灰色** 不符。

## 实现
- 保留 `homeAttitudeCardGlow` / `--ha-card-glow` / `--ha-g` 滚动插值（图2 融合 → 图3 独立）。
- `.ha-card::before` 双径向：
  - **左上**：`--ha-wrap-gold`（`rgba(255,218,168)`）在 **g≈0** 时更强，向下滚动减弱。
  - **右下/右上**：`--ha-wrap-silver`（`rgba(186,194,206)`）在 **g→1** 时增强，白底与银灰边更清晰。
- 卡片底色融合态改为暖灰金 `#f4efe6` → `#fff`；区块底为中性暖灰（非蓝灰）。
- 无 `ha-pastel` / `ha-shell` 整块闪色。

## 版本
**1.9.194** / **VERSION_CODE=231**
