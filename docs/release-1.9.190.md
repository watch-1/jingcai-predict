# 1.9.190 首页「圈子热议」

## 变更
- 首页「比赛态度」标题改为双 Tab：**比赛态度** | **圈子热议**（橙色下划线选中态，默认仍为比赛态度）。
- **圈子热议**：`GET /api/tribe/hot` 按互动（赞/笑/火）+ 回复数 + 近 72 小时时效加权排序，展示各部落热门帖；卡片复用部落 `tf-card` 样式，可点进 `#/tribe-post/:id`。
- 版本：**1.9.190** / **VERSION_CODE=226**

## 自测
1. 首页见两个 Tab，默认「比赛态度」内容与 1.9.139 一致。
2. 切到「圈子热议」出现部落帖列表（无帖时引导去部落）。
3. 点卡片进入帖子详情。
