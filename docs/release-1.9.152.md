# 1.9.152 数据页球队/球星顶栏 · 精简工具行

## 变更
1. **数据顶栏**：底栏在「数据」时，顶栏中部替换为 **球队 · 球星**（与赛程页顶栏上下文切换同一架构）；离开数据页恢复 **部落 · 头条 · 开奖**。
2. **移除工具行**：数据页去掉「刷新」、开奖结果胶囊及「积分 / 射手 / 身价 · 无下注」文案；联赛 pills 与子榜 Tab 保留。
3. **球队子榜**：积分榜、球队身价榜（复用 `/api/club-values`）。
4. **球星子榜**：射手榜、助攻榜、门神榜（筹备占位 `/api/topkeepers`）、球员身价榜（新增 `/api/player-values`）。
5. **默认**：球队 → 积分榜；球星 → 射手榜。`jc_data_section` 持久化一级分类。
