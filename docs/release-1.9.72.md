# 1.9.72 — 运营后台 Admin Console v1

## 内容
独立 `/admin` 暗色中文运营控制台（非 App「我的」）：

1. **管理认证**：`ADMIN_PASSWORD` / `ADMIN_TOKEN` 环境变量；Cookie + Bearer 会话；非管理员 401。
2. **用户**：列表/搜索、封禁解禁、角色与会员天数、基本资料。
3. **会员订单**：列表筛选、标已付 / 取消 / 退款标记（schema 已支持）。
4. **功能开关**：AI 赛前 / AI 聊球 / AI 复盘 / 综合预测报告，写库即时生效。
5. **监控卡片**：AF 配额、球员库缺口、最近入库、版本与 uptime。

## 部署
- 版本 **1.9.72**（web/server；本版无需改 APK）
- 须在 `.env` 配置管理员密码后访问 `/admin`
