# 1.9.274 — 赛程「开奖」顶栏与入口

## 改什么
- **Bug**：赛程顶栏点「开奖」会跳到 `#/results` 并换成首页顶栏「论坛 / 头条 / 开奖」。现改为赛程内 `schChannel=results`，路由保持 `#/schedule`，顶栏仍为 **比分 / 计算器 / 开奖**。
- **产品**：首页、预测顶栏去掉「开奖」Tab；旧链接 `#/results` 自动重定向到赛程开奖视图。
- **未改**：比分、计算器频道；开奖列表与日期条逻辑。
