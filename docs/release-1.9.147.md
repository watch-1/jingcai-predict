# 1.9.147 顶栏高亮修复 · 赛程三钮筛选

## 变更
1. **顶栏 Tab 高亮**：底栏「首页 / 赛程 / 预测 / 数据」不再误亮「部落」绿线；仅 `#/tribe`、`#/news`、`#/results` 时对应顶栏 Tab 高亮。
2. **赛程筛选**：移除「热门 / 关注 / 全部」分段行与「全部 / 进行中 / 未开始 / 已结束」状态 pills；在日期条下增加 **关注 · 未开始 · 已结束** 三钮主筛选（默认 **未开始**），联赛 pills 保留。
3. **列表摘要**：去掉「全部 · 全部」式双通道文案，按当前主筛选项展示场次。
