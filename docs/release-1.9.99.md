# 1.9.99 相对盘口优势（value / edge）

## 公式
- fair_implied = (1/odds) / Σ(1/odds)  （去水）
- our_prob = 1.9.98 校准命中率（引擎倾向那一侧，n≥30）；其它项仅展示盘口结构基率
- edge = our_prob − fair_implied
- 建议关注：edge ≥ 阈值 且 our_prob × odds − 1 > 0
- 阈值：训练校准表上扫 3/4/5/6/8pp，取测试集 ROI 最好且 n≥40 者 → **4pp**
- 只对引擎倾向方向给「建议关注」（全向扫基率在测试集 ROI −19%，已弃用）
