# 1.9.192 首页比赛态度卡片蓝色包裹（修复 Tab 切换渐变闪烁）

## 变更
- 移除首页「比赛态度」区块级 `ha-pastel` / `ha-shell` 共享渐变（滚动整块变海军蓝），避免与「圈子热议」切换时背景闪动/串色。
- 改为 **按卡片** `--ha-card-glow`：卡片滚到列表顶部时，左上角图标区域逐渐出现浅蓝径向光晕（对齐设计图 3「蓝色包裹」）。
- Tab 切回「比赛态度」时 `requestAnimationFrame` 重算光晕。
- 版本：**1.9.192** / **VERSION_CODE=229**

## 自测
1. 首页上下滚动：仅靠近顶部的平台简报卡出现蓝色光晕，下方卡片不会整块同时变蓝。
2. 「比赛态度」↔「圈子热议」快速切换：无整块渐变闪烁。
3. `node test/ui-192-test.js`
