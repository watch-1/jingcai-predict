# 1.9.144 导航与顶栏清理

## 变更
1. **部落切换**：在底部「赛程 / 预测 / 数据」时，顶栏 **部落 | 头条 | 开奖** 仍显示上次内容 Tab 的下划线（默部落），点 **部落** 可回到首页态度流。
2. **移除搜索**：顶栏搜索入口与全局 `#/search` 页下线（深链自动回部落）；保留头条内球队搜索。
3. **赛事详情**：去掉「赛事详情」标题条；深蓝 hero 顶到状态栏下沿，返回与「关注」浮在 hero 上（edge-to-edge）。
4. **去掉模块内页标题**：赛程 / 预测 / 开奖等 `shell-title` 行删除，仅保留日期条、筛选与内容。

## 版本
- Web / `config.js` / `sw.js`：**1.9.144**（`jc-v1.9.144`）
- Android 默认：`VERSION_NAME=1.9.144`、`VERSION_CODE=181`

## 验证
1. 在赛程底 Tab 时顶栏可见且 **部落** 可点回首页。
2. 顶栏无搜索图标；无全局搜索条。
3. 赛事详情无深色标题栏，hero 通顶、仅浮动返回。
4. 赛程 / 预测 / 开奖无重复大字标题行。
