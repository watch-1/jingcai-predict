# 1.9.140 个人知识库画布

## 产品
- 打开知识包后进入 **可编辑画布**：添加节点、拖拽摆放、点选后编辑/删除标题与正文。
- 知识包列表仍可创建/改名/删除；空包提示「打开画布添加节点」。
- 个人预测勾选知识条目流程不变（仍按标题+正文）；画布布局仅影响编辑体验。

## 技术
- SQLite：`kb_pack` 增加 `layout_pan_x/y`、`layout_zoom`；`kb_item` 增加 `pos_x/pos_y`（迁移自动回填网格）。
- API：`PATCH /api/kb/packs/:id/layout`；创建/更新条目可带坐标。
- 前端：`public/js/kb-canvas.js`（平移/缩放/拖拽/双指缩放），接入 `#/kb/pack/:id`。

## 版本
- `config.js` / `sw.js` **1.9.140**；Android 默认 `VERSION_NAME=1.9.140`、`VERSION_CODE=177`。

## 验证
1. 登录 → 我的知识库 → 创建包 → 进入包 → 添加节点并拖动，刷新后位置保留。
2. 点节点 → 编辑 → 保存；选中后删除。
3. 单场「用我的知识库预测」仍能勾选条目并生成结果。
