# 1.9.23 罗马过程数据空缺（AF 队名同名误映射）

## 现象
赛事详情 → 数据 Tab「场均对比」：主队罗马显示「暂无」+「暂无技术统计」，客队皇马正常（近7场）。

## 根因
竞彩队 `132` 的 crest 英文为 `Roma`。`resolveAfTeamId` 用 `/teams?search=Roma` 后按 `nameScore` 取最高分：
斯洛文尼亚业余队 **Roma (AF 22590)** 与查询串完全同名得 1.0，高于意大利 **AS Roma (497)** 的 0.88。
22590 仅有极少杯赛完场且无技术统计 → `reason=no_stats`。皇马 `664→541` 映射正确故一侧有数据。

## 修复
1. `AF_TEAM_SEED`：`132→497`、`664→541`，并补切尔西/拉齐奥/热那亚等；种子可覆盖错误缓存。
2. `resolveAfTeamId`：质量加权（code/founded/主流国家），压低无元数据的同名壳球队。
3. `AF_ZH_EN` / crests：`罗马→AS Roma`，`皇马→Real Madrid`。
4. 预测：单侧过程数据时信心略降；文案提示可能为映射异常。
5. 部署时清除 prod `s:132` / `n:roma` 错误缓存。

## 非问题
API-Football 部分场次/联赛本身无技术统计、配额紧张、账户暂停，仍会导致真实「暂无」——不造假数据。

## 对预测的影响
过程 lean 仅在**双方**都有 averages 时参与打分；单侧缺失时不注入过程倾向，更倚重近况/排名/赔率，信心略降。误映射会使罗马侧永久空，削弱过程交叉验证，但不会用错误球队的数据污染对比。
