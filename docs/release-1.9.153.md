# 1.9.153 赛程联赛标签再点熄灭

## 变更
1. **赛程联赛 pills**：点击未选中的联赛 → 高亮并只显示该联赛场次；**再点一次已高亮的联赛** → 取消选中，回到「全部」场次（与点「全部」等效）。
2. **「全部」**：已选全部时再点「全部」保持全部；熄灭逻辑优先覆盖具体联赛标签。

## 版本
- Web / `config.js` / `sw.js`：**1.9.153**（`jc-v1.9.153`）
- `VERSION.txt`：**1.9.153** / **VERSION_CODE=190**
- Android 默认：`VERSION_NAME=1.9.153`、`VERSION_CODE=190`

## 验证
1. 赛程页：选英超 → 再点英超 → 「全部」高亮、英超不高亮，列表恢复全部场次。
2. `node tools/ui-test.js` 通过。
